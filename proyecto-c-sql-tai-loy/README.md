# Proyecto C — SQL sobre movimientos de almacén (SAP MB51)

**Estado: en construcción · v1 objetivo 30/ago/2026**

## Qué va a contener

10 a 12 consultas comentadas sobre los movimientos de almacén (transacción SAP MB51) de una cadena retail donde trabajé: `GROUP BY`, `JOIN`, `CASE WHEN` y CTEs, cada una respondiendo una pregunta de operación real, no un ejercicio de sintaxis. Una segunda versión reescribe dos o tres de ellas con funciones de ventana.

Los datos de origen son de un tercero y no se publican: al repositorio entra únicamente el resultado anonimizado, con proveedores renombrados bajo el mismo criterio que el Proyecto A.

## Por qué todavía no está aquí

Misma regla que en el Proyecto B: no se publica una carpeta que promete. Cuando exista, va en formato problema → enfoque → resultado, en español e inglés.

# Project C — SQL on warehouse movements (SAP MB51)

**Status: under construction · v1 target Aug 30, 2026**

## What it will contain

10 to 12 annotated queries over the warehouse movements (SAP MB51 transaction) of a retail chain I worked for: `GROUP BY`, `JOIN`, `CASE WHEN`, and CTEs — each one answering a real operational question, not a syntax exercise. A second version rewrites two or three of them using window functions.

The source data belongs to a third party and is not published: only the anonymized output enters this repository, with suppliers renamed under the same criteria used in Project A.

## Why it isn't here yet

Same rule as Project B: no folder that only makes promises gets published. When it exists, it ships in problem → approach → result format, in Spanish and English.
