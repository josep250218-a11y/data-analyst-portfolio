## Cómo leer este repositorio

Cada proyecto es una carpeta con su propio README en formato **problema → enfoque → resultado**, en español e inglés. Cada afirmación se puede verificar dentro del repositorio: el modelo, las medidas, la captura y el dataset están ahí.

## Aviso sobre los datos

Los datos vienen de operaciones reales y están **anonimizados**: clientes, proveedores y modelos renombrados; costos y precios escalados por un factor constante que conserva la proporción real pero no los valores absolutos. Las columnas con prefijo `sim_` son simuladas y están declaradas en cada proyecto. El mapeo entre nombres reales y anónimos no vive en este repositorio ni en ningún otro.

## How to read this repository

## About the data

The data comes from real operations and is **anonymized**: customers, suppliers, and models renamed; costs and prices scaled by a constant factor that preserves the real proportions but not the absolute values. Columns prefixed `sim_` are simulated and declared in each project. The mapping between real and anonymized names does not live in this repository, or in any other.
