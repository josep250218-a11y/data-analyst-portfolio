# Proyecto B — KPIs de almacén desde cero

**Estado: en construcción · fecha objetivo 6/sep/2026**

## Qué va a contener

El sistema de indicadores de un almacén de manufactura que no tenía ninguno, construido desde cero: exactitud de inventario, rotación, aging de stock y nivel de servicio a producción. El valor del caso no es el dashboard: es que las métricas las definí yo, para una operación que gestiono, y se pueden defender una por una.

Porque una carpeta vacía con un README que promete es peor que no tener la carpeta. Cuando el contenido exista, esta nota se reemplaza por el caso completo en formato problema → enfoque → resultado, en español e inglés.
